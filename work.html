03 / EdTech AIMyTeacher: AI Curriculum Engine

What it solves

An AI system that generates structured curriculum content for schools at scale.

DjangoOpenAIVector DBMulti-agent LLM

How it works

  • Multi-stage pipeline: strand and sub-strand analysis, skill extraction, then AI-generated questions mapped to each skill.
  • Dual-model verification: the generating model self-reviews against strict pedagogical rules, then an independent second model validates quality.
  • Semantic deduplication with vector similarity search blocks near-duplicate questions.
  • A question joins the curriculum only after generation, both verifications and deduplication pass.
  • Audit logs at every stage for traceability and prompt improvement.

An in-exam assistant that helps students without handing over answers.

DjangoVector DBStreaming APILLM

How it works

  • Guardrail-enforced LLM responses give only conceptual explanations and hints, preserving academic integrity.

  • A mystery points system rewards students for trying questions on their own first.
  • Parent notifications show which kinds of questions students find hard.
  • Interaction logs let teachers spot common knowledge gaps.
05 / GenAI / RAGInvoice Compare AI

DjangoReactOpenAIPrompt engineering

How it works
